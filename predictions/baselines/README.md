# Baseline Predictions

Baseline summary files for the GitHub release.

Included files:

- `baseline_metrics.tsv`: compact family-heldout baseline metrics used for
  manuscript positioning.
- `small_example_predictions.csv`: toy long-format prediction file for smoke
  testing the evaluator.

Full baseline prediction matrices and model outputs are packaged in the Zenodo
`ViruFunc_Atlas_v1.0_BaselinePredictions.tar.gz` bundle.
