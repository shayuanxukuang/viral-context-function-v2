# License Decision Required

The Atlas-Core release should include explicit licenses for code and data, but
the license must be selected by the project owner or institution.

Recommended decisions before public release:

- Code license: for example MIT, BSD-3-Clause, Apache-2.0, or another approved
  institutional open-source license.
- Data/resource license: for example CC-BY-4.0, CC0, or a more restrictive
  data-use notice if upstream database terms require it.
- Third-party data notices: include NCBI, UniProt, InterPro/Pfam/CDD, PHROG,
  Phold/Foldseek, and model-weight/database terms where applicable.

Do not publish the benchmark as a community resource until this file is replaced
or supplemented by the chosen license files.
